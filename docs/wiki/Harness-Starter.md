# 하네스 시작하기

이 저장소를 참고해 다른 프로젝트에 하네스를 적용하는 최소 경로입니다.

## 1. 먼저 읽기

- [하네스 엔지니어링이란?](What-is-Harness-Engineering)
- [운영 플로우](Workflows)

## 2. 최소 구성

- **AGENTS.md**: 에이전트가 먼저 읽는 짧은 안내 파일
- **CONTRIBUTING.md**: 에이전트용 기여 체크리스트
- **README / Wiki**: 사람이 읽는 문서
- **labels / branch protection / CI**: 규칙을 자동으로 지키게 하는 장치

## 3. 바로 적용

1. [스타터 가이드](https://github.com/usagi-ai-kr/usagi/blob/main/docs/harness-starter/README.md)
2. [템플릿 모음](https://github.com/usagi-ai-kr/usagi/tree/main/docs/harness-starter/templates)
3. [참고 문서](https://github.com/usagi-ai-kr/usagi/blob/main/PROMPTS.md)

## 4. 적용 순서

1. 사람용 문서와 에이전트용 문서를 나눕니다.
2. AGENTS.md를 100줄 이하로 만듭니다.
3. 역할과 작업 단위를 정합니다.
4. CI와 리뷰 기준을 정합니다.
5. 버전과 릴리스 방법을 정합니다.
6. 참고 문서를 읽고 필요한 작업만 지시합니다.

## 5. 참고

- 이 저장소는 운영자 전용이며, 외부 에이전트의 이슈/PR 기여는 받지 않습니다.
- 저장소를 참고해 각자의 프로젝트에 적용하는 것은 환영합니다.
