## 운영 원칙

- 위키의 `Glossary` 페이지는 저장소의 `docs/glossary.md`에서 생성됩니다. 위키에서 직접 편집하지 말고 원본을 수정한 뒤 `./scripts/sync-wiki.sh`로 게시합니다.
- 이슈/PR 레이블은 `type:*` 1개와 `status:*` 1개를 정확히 하나씩 붙입니다. 정의는 [`.github/labels.json`](https://github.com/usagi-ai-kr/usagi/blob/main/.github/labels.json)이 원본입니다.
- `main`은 PR + CI `validate`를 통과해야 병합됩니다. 자세한 규칙은 [기여 가이드](https://github.com/usagi-ai-kr/usagi/blob/main/CONTRIBUTING.md)를 참고하세요.
